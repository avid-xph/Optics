# ⑥ 编码单元与奈奎斯特采样分析

> 状态：理论 + 单窗口 CPU 验证 + **全量 GPU 结果已补齐**（6 场景 × σ ∈ {0,0.5,1.0} × δ ∈ {0,0.25,0.5} × cell ∈ {1,2,3,4,6,8}，ADMM-TV + T-free，T=8）。
> 代码：`sci_ablation/forward.py` 的 `image_mask` / `ExperimentCUP(psf_sigma, mask_shift)`，PR #14。
> 数据：`results/ablation/nyquist_s{σ}_d{δ}.csv`；汇总：`report/analyze_nyquist.py`；分支 `exp/nyquist-gpu-scan`。

## 1. 问题

CUP 的编码 mask（DMD 或光刻掩膜）经中继光学成像到 CCD 上。设一个编码单元在 CCD 上的成像尺寸为
c 个像元（实验 ② 的 `cell`）。工程上的奈奎斯特条件是 **c ≥ 2（常取 3–4）**。

实验 ② 在理想仿真里得到的结论正好相反：cell 1→10 单调变差（ADMM-TV 25.87 → 15.46 dB），
cell=1 最好。原因是理想仿真里 mask 与像元网格严格对齐、没有光学模糊，c=1 不付任何代价，
只享受"编码更随机、条件数更好"的好处。所以 ② 只说明了 trade-off 的一半：**c 越大，编码越粗，
空间分辨率越低**。另一半，也就是 **c 越小，对成像缺陷越敏感**，需要把成像过程放进前向模型才能看到。

## 2. 模型

测量用物理 mask，重建用名义 mask（按设计图标定的系统）：

    M_phys = Shift_δ( G_σ * M_nom )

- G_σ：mask→CCD 的高斯 PSF（σ 以像元为单位）
- Shift_δ：亚像元错位 δ（两个方向，线性插值）

重建算子与测量算子不一致，误差项为 A_phys − A_nom，其大小由下面两个量决定。

## 3. 两个可预测的量

### 3.1 模糊：编码对比度 = PSF 在单元基频处的 MTF

c×c 随机二值 mask 的能量主要在 f ≤ 1/(2c) 周期/像元。高斯 PSF 的 MTF 为
MTF(f) = exp(−2π²σ²f²)，在 f = 1/(2c) 处：

| σ（像元） | c=1 | c=2 | c=3 | c=4 | c=6 | c=8 |
|---|---|---|---|---|---|---|
| 0.5 | 0.29 | 0.74 | 0.87 | 0.93 | 0.97 | 0.98 |
| 0.7 | 0.09 | 0.55 | 0.76 | 0.86 | 0.94 | 0.96 |
| 1.0 | 0.01 | 0.29 | 0.58 | 0.74 | 0.87 | 0.93 |

c=1 时，σ=0.5 像元的轻微模糊就把编码对比度压到 29%；c=2 还剩 74%。
经验规则：**要保住 ≥70% 的对比度，需要 c ≳ 4σ**。σ≈0.5 时就是 c≥2，与奈奎斯特条件一致。

### 3.2 错位：混合像元比例

δ ≠ 0 时，每个单元在每个方向上有 1 列/行像元跨在两个单元的边界上，值是两个随机编码的混合，
与名义 mask 不符。二维混合像元比例为 1 − (1 − 1/c)²：

| c | 1 | 2 | 3 | 4 | 6 | 8 |
|---|---|---|---|---|---|---|
| 混合像元比例 | 100% | 75% | 56% | 44% | 31% | 23% |

c=1 时所有像元都和名义值不符；c 增大，失配像元按 ~2/c 减少。

## 4. 单窗口验证（CPU，kobe，T=8，窗口 0，ADMM-TV，noise=0.01，seed=0）

| σ / δ | c=1 | c=2 | c=3 | c=4 | c=6 |
|---|---|---|---|---|---|
| 0 / 0（理想） | **26.55** | 24.80 | 23.69 | 22.93 | 20.83 |
| 0.5 / 0 | **23.87** | 23.58 | 22.80 | 22.29 | 20.43 |
| 0 / 0.5 | 20.41 | **20.62** | 20.35 | 20.12 | 18.92 |
| 0.7 / 0.5 | 20.13 | **20.17** | 19.98 | 19.91 | 18.73 |

- 模糊 σ=0.5 的损失：c=1 −2.68，c=2 −1.22，c=3 −0.89，c=4 −0.64，c=6 −0.40 dB。
  损失顺序与 3.1 的 MTF 顺序一致（对比度越低，损失越大）。
- 半像元错位后 c=2 反超 c=1，**最优 c 从 1 移到 ~2**。
- 错位对所有 c 都造成 2–6 dB 损失，比模糊大：标定误差是比光学模糊更主要的风险。

### 5.3 T-free − ADMM-TV：各自取最优 c 时

真实系统设计时会为每个方法选它自己的最优 c，所以这里比两个方法各自的最好结果
（5.1 与 5.2 的粗体格）：

| σ \ δ | 0 | 0.25 | 0.5 |
|---|---|---|---|
| **0** | **+2.11** | −0.12 | −0.84 |
| **0.5** | +0.18 | −0.89 | −1.21 |
| **1.0** | −1.70 | −1.73 | −1.90 |

- **理想系统 T-free 领先 2.11 dB**（28.05 vs 25.94，都在 c=1）。
- **轻微缺陷（σ=0.5 或 δ=0.25 单独出现）时基本打平**（+0.18 / −0.12 dB），
  只要选 c=2，T-free 不吃亏。
- **缺陷再大一些就落后 0.8–1.9 dB**，σ=1.0 时三种错位都落后 ~1.7–1.9 dB。

### 5.4 两个效应要分开：mask 统计偏移 vs mask 失配

T-free 在大 c 下落后，**理想成像时就已经存在**（σ=0, δ=0：c=4 −1.13，c=6 −2.65，
c=8 −2.54 dB）。这是 cell 的分布偏移：T-free 训练时只见过逐像素随机 mask（c=1），
和模糊、错位无关。所以不能用大 c 处的差距来说明"对失配更脆弱"。

衡量失配敏感度的干净做法：**同一个 c 下，相对自己理想结果的下降**。在 c=2（有缺陷时两者的最优 c）：

| σ / δ | ADMM-TV 下降 | T-free 下降 | 比值 |
|---|---|---|---|
| 0.5 / 0 | −2.26 | −3.70 | 1.6× |
| 0 / 0.25 | −3.60 | −5.34 | 1.5× |
| 0 / 0.5 | −6.42 | −8.88 | 1.4× |
| 0.5 / 0.5 | −6.53 | −9.36 | 1.4× |
| 1.0 / 0 | −6.35 | −9.67 | 1.5× |
| 1.0 / 0.5 | −7.37 | −10.66 | 1.4× |

**T-free 对 mask 失配的敏感度约为 ADMM-TV 的 1.4–1.6 倍**，在所有条件下一致。
它多出来的 2.1 dB 优势就是被这个更陡的下降吃掉的。

可能的原因（未验证）：T-free 的学习步长和去噪先验是在"测量与名义算子严格一致"的数据上训练的，
失配留下的结构化残差不在它的训练分布里；ADMM-TV 的 TV 先验是通用的，不依赖这一点。

### 5.5 其他观察

- **最优 c 迁移**：理想系统 c=1；有缺陷时两个方法的最优 c 几乎都是 c=2
  （唯一例外：ADMM-TV 在 σ=1.0/δ=0.5 时 c=1，但 c=1–3 只差 0.5 dB，曲线很平）。
- **错位比模糊伤得多**：c=2 时，ADMM-TV 在 δ=0.5 下降 6.42 dB，在 σ=0.5 只降 2.26 dB；
  T-free 分别降 8.88 和 3.70 dB。
- **第 3.1 节的规则 c ≳ 4σ 不能用来预测最优 c**：它在 σ=0.5 时给出 c≥2，和实测一致；
  但 σ=1.0 时给出 c≥4，实测最优仍是 c=2。原因是大 c 同时损失空间分辨率（实验 ②），
  这个代价比多保住的对比度更大。c ≳ 4σ 只是"对比度保住 70%"的阈值，不是最优点。
- 局限：`image_mask` 的亚像元平移用 `torch.roll`，边缘几个像元会循环回绕。

## 6. 结论

1. ② 和 ⑥ 是同一个 trade-off 的两面：c 小 → 编码细、条件数好，但对模糊/错位敏感；
   c 大 → 鲁棒，但编码粗、分辨率低。
2. 理想系统最优 c=1；有模糊或标定误差的真实系统，在本扫描的范围内（σ ≤ 1、δ ≤ 0.5）
   最优 c=2，与奈奎斯特 c ≥ 2 吻合。
3. 设计规则：取 c=2；标定误差 δ 是比光学模糊更大的风险，要远小于 1 个像元。
4. **T-free 的"T 无关"不等于"对成像缺陷鲁棒"。** 它对 mask 失配的敏感度是 ADMM-TV 的
   1.4–1.6 倍：轻微缺陷时与 ADMM-TV 打平，缺陷较大时落后 0.8–1.9 dB。
   另外它还受训练时 mask 统计（c=1）的约束，大 c 下即使理想成像也落后。
   "一套权重跑任意 T"已证明，"一套权重跑任意 mask 和成像条件"没有证明。

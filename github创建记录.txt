这两个需求其实用同一套机制解决：**SSH 密钥**。GitHub 的规则是一把公钥只能绑定一个账号，但一个账号可以绑定多把公钥。所以：

- **一台电脑、两个账号**：这台电脑生成两把密钥，各绑一个账号，再用 SSH 配置告诉 Git 哪个仓库用哪把。
- **多台电脑、一个账号**：每台电脑各自生成自己的密钥，都添加到同一个账号上。不要把私钥拷来拷去。

## 执行顺序

1. 先在**主力电脑**上完成"双账号切换"的完整配置（第一部分）。
2. 再在**其他每台电脑**上重复生成密钥、添加公钥、写配置（第二部分）。配置文件可以直接复制，密钥要在每台机器上重新生成。

---

## 第一部分：一台电脑上使用两个账号

假设两个账号分别叫 `personal`（个人）和 `work`（工作）。

### 1. 生成两把密钥

```bash
ssh-keygen -t ed25519 -C "personal@example.com" -f ~/.ssh/id_ed25519_personal
ssh-keygen -t ed25519 -C "work@example.com"     -f ~/.ssh/id_ed25519_work
```

Windows 用户请在 Git Bash 里执行这些命令。

### 2. 把公钥分别添加到对应账号

登录对应账号，进入 GitHub → Settings → SSH and GPG keys → New SSH key，粘贴公钥内容：

```bash
cat ~/.ssh/id_ed25519_personal.pub   # 加到 personal 账号
cat ~/.ssh/id_ed25519_work.pub       # 加到 work 账号
```

### 3. 编辑 `~/.ssh/config`，给每个账号起一个主机别名

```
Host github-personal
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_personal
    IdentitiesOnly yes

Host github-work
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work
    IdentitiesOnly yes
```

`IdentitiesOnly yes` 很关键。没有它，SSH 可能会先用错的密钥登录成功，导致你以错误的账号身份推送。

### 4. 测试连接

```bash
ssh -T git@github-personal   # 应显示 Hi personal!
ssh -T git@github-work       # 应显示 Hi work!
```

### 5. 克隆或修改仓库地址时用别名代替 `github.com`

```bash
# 新克隆
git clone git@github-work:company/project.git

# 已有仓库改地址
git remote set-url origin git@github-personal:me/my-repo.git
```

### 6. 按目录自动切换提交身份（推荐）

SSH 只决定"用哪个账号推送"。提交记录里的作者名和邮箱由 Git 配置决定，也要区分。建议把两类项目放在不同目录，比如 `~/personal/` 和 `~/work/`，然后在 `~/.gitconfig` 里写：

```ini
[user]
    name = Your Name
    email = personal@example.com

[includeIf "gitdir:~/work/"]
    path = ~/.gitconfig-work
```

再新建 `~/.gitconfig-work`：

```ini
[user]
    name = Your Name
    email = work@example.com
```

这样 `~/work/` 下的所有仓库会自动使用工作邮箱。注意路径末尾的 `/` 不能省。在 Windows 上可以写成 `gitdir/i:C:/Users/你/work/`，加 `/i` 表示忽略大小写。

在仓库里运行 `git config user.email` 可以确认当前生效的邮箱。

## 第二部分：多台电脑使用同一个账号

在每一台新电脑上：

1. **重新生成密钥**（同第一部分第 1 步）。建议在注释里注明机器，例如 `-C "work@example.com laptop"`。
2. **把这台机器的公钥添加到同一个 GitHub 账号**。一个账号下可以有多把密钥，建议标题写上电脑名，例如 "MacBook"、"公司台式机"。
3. **复制 `~/.ssh/config`、`~/.gitconfig`、`~/.gitconfig-work`** 这几个配置文件过去，按需调整路径。
4. 用 `ssh -T` 测试连接。

每台机器使用独立密钥的好处是：某台电脑丢了或不用了，只需在 GitHub 上删掉那一把公钥，其他电脑不受影响。

## 补充：如果你习惯用 HTTPS 而不是 SSH

GitHub CLI 可以登录多个账号并切换：

```bash
gh auth login        # 依次登录两个账号
gh auth switch       # 在账号之间切换
gh auth setup-git    # 让 git 使用 gh 的凭据
```

这种方式需要手动切换，容易忘记切换而用错账号。SSH 别名方案按仓库自动区分账号，更适合两个账号长期并用的情况。
